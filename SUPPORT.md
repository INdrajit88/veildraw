# Support

Thanks for your interest in `pgp` (Private Giveaway Platform on Midnight Network).

## Getting Help

- **Documentation**: See the [README](README.md) for project overview, setup, and integration.
- **Contributing**: Read [CONTRIBUTING.md](CONTRIBUTING.md) before opening pull requests.
- **Security issues**: Follow [SECURITY.md](SECURITY.md) — do not open public issues for vulnerabilities.

## Asking Questions

- Open a discussion or issue on the repository for general questions.
- For Midnight-specific questions (Compact, proof server, preprod faucet), refer to the [Midnight documentation](https://docs.midnight.network/).

## Reporting Bugs

Use the bug report issue template and include:

1. The exact command you ran and its full output.
2. Relevant log file under `pgp-cli/logs/`.
3. Your Node.js version (`node -v`) and whether Docker was running for the proof server.

## What We Don't Support

- Forks of this repository that modify the Compact circuit without disclosing the change.
- Issues reproducible only on chains other than Midnight Preprod Remote.
- Questions about Midnight wallet extensions (Lace / 1AM) — consult their respective maintainers.
